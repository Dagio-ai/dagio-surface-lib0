# Dagio lib0

This release is based on lib0 0.2.119 at upstream commit f7fd1ac39041b9d2c923c8a0befce6995804ed31.
It moves style serialization from the DOM module to the string module. The DOM export remains compatible.
The package retains the upstream MIT licence. Internal imports use the published Dagio package name.

Run npm ci, npm run lint, npm test, npm run types and npm run dist before publishing.
