# Dagio lib0 releases

Dagio publishes its compatible lib0 releases as `@dagio-ai/surface-lib0` in GitHub Packages.
The source of each release is the `dagio-v<version>` tag, based on the corresponding upstream
release commit. The upstream MIT licence is included with the package.

Surface consumes the scoped package through the `lib0` npm alias. Run the `Publish Dagio lib0`
workflow with the release tag to build, test and publish the exact source of that tag.
